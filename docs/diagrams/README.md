# Diagrams

Architecture and database diagrams for the Grove & Root Apple Store project.

## Files

| File | Description |
|------|-------------|
| [architecture.md](./architecture.md) | Full system architecture (deployment, app layers, auth, checkout, routes) |
| [erd.md](./erd.md) | Entity Relationship Diagram with JPA mapping notes |
| [deployment.mmd](./deployment.mmd) | AWS deployment diagram (raw Mermaid) |
| [application.mmd](./application.mmd) | Application layer diagram (raw Mermaid) |
| [erd.mmd](./erd.mmd) | ERD diagram (raw Mermaid) |

## How to View

- **GitHub**: Open any `.md` file — Mermaid blocks render automatically.
- **VS Code / Cursor**: Install the [Mermaid extension](https://marketplace.visualstudio.com/items?itemName=bierner.markdown-mermaid) and preview the markdown files.
- **Export PNG/SVG**: Paste contents of `.mmd` files into [mermaid.live](https://mermaid.live) and export.
